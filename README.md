# 3D 模型檢視器（Model Viewer）

把 SketchUp 匯出的 OBJ / STL / GLB 放上網，嵌入 Google 協作平台，讓同學用滑鼠轉動模型，當作繪製三視圖的依據。

- 同學：拖曳旋轉、滾輪縮放、右鍵或 Shift＋拖曳平移；一鍵切到前視／俯視／右側／左側／後視／仰視／等角；右上角的視角方塊點哪一面就看哪一面
- 平行投影（預設）／透視切換：平行投影沒有近大遠小，和三視圖的看法相同
- 「隱藏線」：被擋住的邊以虛線透出來（曲面、孔的輪廓線也算）
- 「量測」：點兩個點量距離，並拆成寬／高／深三個分量；點會自動吸附到端點與稜線
- 左上角顯示外形總尺寸（寬 × 深 × 高）
- 老師可以在每個連結上分別關掉量測、總尺寸、隱藏線按鈕（例如考試時）

單一檔案 `index.html`，three.js 由 CDN 載入。讀檔與網格修補（SketchUp 的凹多邊形面、接縫不對齊、雙面匯出）沿用 [`../3 side view generator`](../3%20side%20view%20generator/) 的程式；改那邊的幾何管線時這邊也要一起改。

**線上版：** 尚未發布（見下方「第一次設定」）

## 老師的流程

1. **SketchUp 匯出**：檔案 → 匯出 → 3D 模型 → 選 OBJ（建議）或 STL。
   - OBJ 的「選項」裡「交換 YZ 座標（Y 軸朝上）」維持勾選，單位選公釐
   - 網頁版 SketchUp 只能匯出 STL，也可以用
   - 檔名建議用英文、數字（例如 `w05-bracket.obj`），網址比較好看
2. **放進 `models/` 資料夾**（可以再分子資料夾）。OBJ 附帶的 `.mtl` 用不到，放不放都可以。
3. **雙擊 `發布模型.command`**：自動更新模型清單、上傳到 GitHub，並開啟線上的老師設定頁。GitHub Pages 約 1～2 分鐘後更新。
4. **在設定頁**選模型，看右上角方塊的「前」是不是你要同學畫前視圖的方向；不對就用「水平轉 90°／前後翻 90°／左右翻 90°」轉到對。需要的話改標題、起始視角、關掉某些功能。
5. 按「複製網址」。
6. **Google 協作平台**：插入 → 嵌入 → 依網址 → 貼上（若出現選項選「整個網頁」）→ 插入，再把嵌入框的高度拉到約 500px 以上。

> 還沒發布的檔案也可以先預覽：開啟設定頁（線上版網址後面加 `?teacher`，或直接雙擊 `index.html`），把檔案拖進左邊的框。

> **注意：這個 repo 是公開的**，`models/` 裡的檔案任何人都下載得到。考試用的模型請考前再發布。

## 網址參數

設定頁會自動產生，一般不用手打。

| 參數 | 意思 | 預設 |
|---|---|---|
| `m` | 模型檔（`models/` 底下的路徑） | 必填 |
| `up=z` / `up=y` | 來源檔哪一軸朝上 | STL 為 z，其他為 y |
| `rot` | 擺放轉動，每個字母代表繞該軸轉 90°（`x`、`y`、`z`） | 不轉 |
| `u` | 檔案單位（1 = mm、10 = cm、1000 = m、25.4 = inch） | OBJ 讀檔頭、STL 為 mm、GLB 為 m |
| `a` | 稜線角度（兩面夾角大於此值才畫線） | 30 |
| `view` | 起始視角：`iso`、`front`、`top`、`right`、`left`、`back`、`bottom` | `iso` |
| `proj=p` | 起始用透視 | 平行投影 |
| `measure=0` / `dims=0` / `hidden=0` | 關掉量測／總尺寸／隱藏線按鈕 | 都開 |
| `title` | 左上角標題 | 檔名 |
| `teacher` | 開啟老師設定頁（可加在既有的連結上繼續修改） | — |

座標慣例與三視圖產生器相同：模型的前方朝 +Z、上方朝 +Y；寬 = X、高 = Y、深 = Z。

## 第一次設定（只做一次）

在這個資料夾開終端機：

```bash
gh repo create superqqming/model-viewer --public --source . --push
gh api -X POST repos/superqqming/model-viewer/pages -f "source[branch]=main" -f "source[path]=/"
```

完成後線上版是 `https://superqqming.github.io/model-viewer/`，老師設定頁是後面加 `?teacher`。之後只要雙擊 `發布模型.command`。

這個資料夾在 Hub 的 `.gitignore` 裡排除，自己是一個獨立的 git repo。

## 本機測試

```bash
python3 -m http.server 8796
```

開啟 <http://localhost:8796/?teacher>。直接雙擊 `index.html` 會開設定頁，但讀不到 `models/` 清單，只能用拖曳預覽。

## 已知限制

- 不讀 SketchUp 的顏色與材質，模型一律畫成白色加黑色稜線（比較接近圖面）
- 不支援 Draco 壓縮的 GLB；`.gltf` 需要另外的 `.bin`，請改匯出 `.glb`
- 三角面很多（數十萬面以上）時載入較慢，可在 SketchUp 減少圓弧段數後再匯出
- 量測只吸附到端點與稜線上的點；圓心、中點不會吸附
- 網格模型的圓弧是多邊形近似，量到的「直徑」是多邊形頂點間的距離
